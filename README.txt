3. Navigate Home, Our Story, Work, Services and Contact.

IMPORTANT — VIMEO ACCESS
The iframe is the exact URL and query parameters supplied by the owner:
https://player.vimeo.com/video/357010673?badge=0&autopause=0&player_id=0&app_id=58479
If Vimeo requests a login, the Vimeo video owner must check the video's privacy (not Private), its embedding permissions, and allowlisted domains. Unlisted embeds can require the actual Vimeo-provided privacy hash, if that video is unlisted; use the embed code copied directly from Vimeo for the current video's privacy state. A browser file:// preview can also be rejected by domain-restricted embeds; test again after deployment on joshuasteichen.com.
A Vimeo player is an online embed, not a locally bundled MP4. No outside site can override Vimeo's playback permissions.

CONTACT FORM
The button opens a prefilled email message via the visitor's installed email application. It does not automatically transmit data.
